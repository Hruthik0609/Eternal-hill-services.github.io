# Eternal Hill Services LLC Website

A responsive static website for Eternal Hill Services LLC, designed for GitHub Pages.

## Files

- `index.html` — website structure and content
- `styles.css` — responsive design, animations, colors, layout
- `script.js` — mobile navigation, scroll animations, contact form mailto behavior
- `assets/logo.png` — supplied Eternal Hill Services logo

## GitHub Pages

1. Upload all files to the repository root on the `main` branch.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.
6. GitHub will publish the site at the repository's Pages URL.

## Contact form

GitHub Pages is static hosting, so the included form opens the visitor's email application using `mailto:`. No server or API key is required.
